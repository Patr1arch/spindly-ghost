# Графический редактор

## Задача:
Необходимо разработать простейший векторный графический редактор, позволяющий пользователю создавать и редактировать графические объекты на рабочей области

Приложение должно предоставлять графический интерфейс с рабочей областью (холстом), на которой пользователь может размещать графические объекты, выбирать их, перемещать и изменять их свойства.

В качестве основных графических объектов необходимо поддержать как минимум:
- Прямоугольник;
- Эллипс (окружность).

## Технологии и ограничения:

- Рекомендуемый язык программирования: C#;
- Рекомендуемый фреймворк для разработки графического интерфейса: Avalonia UI;
- Допускается использование других языков программирования и GUI-фреймворков (только предупредите меня заранее, что будете использовать);
- Не допускается использование готовых графических библиотек, реализующих основную функциональность разрабатываемого редактора;
- Допускается использование стандартных возможностей выбранного языка программирования и GUI-фреймворка;

## Функциональные требования:

1. Создание графических объектов;

Пользователь должен иметь возможность создавать прямоугольники и эллипсы двумя способами:
- Выбрать соответствующий инструмент и нарисовать фигуру на рабочей области с помощью мыши;
- Создать фигуру с помощью соответствующей кнопки интерфейса.

2. Работа с графическими объектами;

- Отображение нескольких графических объектов на рабочей области;
- Выбор существующего объекта с помощью мыши;
- Перемещение выбранного объекта с помощью мыши;
- Изменение размеров выбранного объекта с помощью специальных маркеров на его границах;
- Удаление выбранного объекта.

Если несколько объектов перекрывают друг друга, при выборе должен учитываться порядок их отображения.

3. Работа со свойствами объектов;

Пользователь должен иметь возможность изменять основные свойства выбранного объекта:
- Цвет заливки;
- Цвет границы;
- Толщину границы;

4. Взаимодействие с рабочей областью;
- Отображение всех созданных объектов.
- Взаимодействие с объектами при помощи мыши;
- Визуальное выделение выбранного объекта.

## Требования к проектированию:

При разработке приложения необходимо учитывать принципы SOLID. Не следует искусственно усложнять архитектуру ради формального применения отдельных принципов. Однако студент должен понимать все принципы SOLID и уметь объяснить их применение в своём проекте.

## Дополнительные возможности:

Реализация дополнительных возможностей может быть оценена дополнительными баллами (максимум два балла, по баллу за подпункт):
- Поддержка дополнительных типов графических объектов (линия, треугольник, многоугольник и другие);
- Изменение порядка отображения объектов (перемещение на передний или задний план);
- Копирование и дублирование объектов;
- Отмена и повтор последнего действия (Undo/Redo);
- Сохранение и загрузка проекта.
- Экспорт рабочего пространства в графический формат (PNG, SVG и другие).

## Как запустить
Выполните в консоли проекта:
```
dotnet build
```
После успешной сборки запустите проект:
```
dotnet run
```
